# 실습 후 비교·자기 점검

## 최소 수정과 원리

```text
연결을 autocommit=True로 열기 → PRAGMA foreign_keys = ON → connection.autocommit = False → 반환
```

foreign_keys 설정을 열린 트랜잭션 안에서 바꾸려 하면 적용되지 않는다. 명령의 존재가 아니라 실행 시점과 조회한 설정값을 확인해야 한다.

수정 뒤 main·solution의 8개 검사 모두 통과하는지 확인한다.
전체 수정 코드는 solution.py에서 비교한다. 검사 기대값이나 샘플 데이터를 바꾸지 않는다.

## 확인 질문 답

1. **FK는 어떤 사실을 보장하는가?**

   참조 값에 대응하는 부모 키가 존재해야 함을 검사한다.

2. **PRAGMA는 한 번만 켜면 모든 연결에 적용되는가?**

   아니다. 사용하는 연결마다 설정하고 확인한다.

3. **트랜잭션 안에서 켜면?**

   foreign_keys 변경이 적용되지 않는다.

4. **왜 True 다음 False로 바꾸는가?**

   트랜잭션 밖에서 설정한 뒤 업무 변경을 명시적으로 확정·취소하기 위해서다.

5. **RESTRICT는 자동 연쇄 삭제인가?**

   아니다. 자식이 있는 부모 삭제를 거절한다.

6. **PRAGMA foreign_key_check 결과 []는?**

   검사 시점에 참조 위반이 발견되지 않았다는 뜻이다.
