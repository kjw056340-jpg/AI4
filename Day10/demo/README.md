# note-demo

간단한 회원 기능과 제목·내용 중심의 게시판 목업입니다. 외부 패키지 없이 Node.js 20 이상에서 실행됩니다.

```sh
node server.js
```

브라우저에서 http://localhost:3000 을 엽니다. 검증은 `node --test`로 실행합니다.

- 회원가입, 로그인·로그아웃, 비밀번호 찾기 목업
- 제목 목록과 검색, 기본 10개씩 페이징, 상세 조회
- 작성자 본인의 글 수정·삭제, 회원 댓글 등록
- 제목·본문·댓글·닉네임 금칙어 마스킹
- 관리자 키워드 추가·삭제, 변형 표현 감지, 실시간 미리보기

로그인 창의 ‘일반 회원’·‘관리자’ 버튼으로 바로 체험할 수 있습니다.

| 계정 | 이메일 | 비밀번호 |
| --- | --- | --- |
| 일반 회원 | demo@note.demo | demo1234 |
| 관리자 | admin@note.demo | admin1234 |

데이터는 현재 브라우저의 localStorage에 저장됩니다. 초기 샘플 글은 23개입니다. 비밀번호는 요청한 목업 범위에 따라 평문이며 실제 비밀번호를 사용하면 안 됩니다. 비밀번호 찾기는 실제 메일을 보내지 않습니다. 여러 브라우저 간 데이터 공유나 실제 서버 인증은 제공하지 않습니다. 브라우저 개발자 도구에서 `note-demo-v1` 항목을 삭제하면 초기화됩니다.

## 설계 문서

- [최소 화면 구성, ERD, 테이블 명세](docs/design.md)
- [PostgreSQL 테이블 생성 SQL](schema.sql)

SQL은 향후 DB 연결용 설계로, 현재 앱에 자동 적용되지 않습니다. 현재 목업은 UUID·중첩 댓글·문자열 금칙어 배열을 사용하며, DB 전환 시 문서의 관계형 테이블로 매핑합니다. 서버에서 소유권·관리자 권한을 재검증하고 비밀번호를 해시로 교체해야 합니다. SNS 로그인·실제 비밀번호 재설정은 향후 범위입니다.

금칙어 선정의 참고 자료와 조사일은 설계 문서 및 관리자 화면에서 확인할 수 있습니다. 화면의 웹 글꼴은 네트워크 연결이 없으면 기본 글꼴로 대체됩니다.
