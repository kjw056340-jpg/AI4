# note-demo 구현 및 검증 계획

기준일: 2026-10-27 (Asia/Seoul)

사용자의 구현 진행 요청에 따라 기존 목업을 보완하고 테스트·실행·배포 문서를 갱신한다.

| 순서 | 작업 | 완료 기준 |
| --- | --- | --- |
| 1 | 기존 회원·게시판·댓글·금칙어 기능 및 최소 화면·ERD 검토 | 구현과 설계 문서의 범위가 일치 |
| 2 | 정적 호스팅 경로 호환성 수정 | 루트와 `/note-demo/` 하위 경로에서 CSS·JS 참조가 올바르게 계산됨 |
| 3 | 자동 테스트 보강 및 실행 | 페이징·마스킹·가입 검증·소유권과 실제 HTTP 응답 테스트 통과 |
| 4 | 공식 최신 문서 확인 | Node.js LTS 및 GitHub Pages 절차·액션 버전 확인 |
| 5 | 배포 설정 및 README 갱신 | 테스트 성공 후 public 폴더만 배포하는 워크플로와 재현 가능한 안내 제공 |

현재 범위는 브라우저 저장소 기반 목업이다. 실제 DB 연결·서버 인증·SNS 로그인·메일 전송은 향후 구현 항목으로 유지한다. 이번 작업은 배포 준비까지 수행하며 외부 저장소 생성·코드 업로드·실제 공개 배포는 실행하지 않는다.
