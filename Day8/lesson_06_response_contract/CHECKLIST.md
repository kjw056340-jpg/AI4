# 6차시 제출 점검

- [ ] 계약을 읽고 실제 실행 전에 상태·본문을 예상했다.
- [ ] Swagger의 Example/Responses와 실제 Server response를 구분했다.
- [ ] TEST_CASES 정상·실패·핵심 회귀를 실행했다.
- [ ] 수정 전 실패를 재현하고 입력·실제 결과를 기록했다.
- [ ] CODEX_PROMPTS의 생성·분석·수정·검토 활동을 수행했다(또는 동료 검토).
- [ ] AI 테스트의 기대값을 계약에 대조하고 누락을 보강했다.
- [ ] 최소 수정 후 python -m pytest -q test_api.py를 실행했다.
- [ ] 서버 재시작 후 같은 Swagger 입력도 재확인했다.
- [ ] 새 API·미사용 코드·다음 차시 기능을 추가하지 않았다.
- [ ] REPORT_TEMPLATE을 실제 결과로 채우고 미검증 한계를 적었다.
- [ ] main.py와 필요한 학생 테스트·보고서를 제출한다. .venv와 캐시는 제외한다.
