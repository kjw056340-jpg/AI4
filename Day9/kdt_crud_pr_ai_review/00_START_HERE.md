# CRUD 통합 + GitHub PR + AI 코드 리뷰 | 8차시 과정

현재 묶음에는 8차시 **전체 개요**와 **1차시 상세 실습**만 포함됩니다. 나머지 차시의 코드를 앞당겨 배포하지 않습니다.

1. `COURSE_OVERVIEW.md`에서 전체 흐름 읽기
2. `lesson_01/README.md`의 CMD 설치 및 실행 안내 확인
3. `lesson_01/main.py` → `lesson_01/check.py` → `lesson_01/CODEX_PROMPTS.md`
4. 강사는 `lesson_01/TEACHER.md`, `lesson_01/VERIFICATION.md`, `lesson_01/lesson_scope.json` 확인

1차시 실습 ZIP도 별도 제공됩니다.

## 2~8차시 완성본 안내

각 차시는 해당 폴더의 `README.md` → `CODE_GUIDE.md` → `CODEX_PROMPTS.md` → `check.py` 순서로 진행합니다. `python check.py main`은 버그 재현으로 실패하고 `python check.py solution`은 통과합니다. 5~8차시는 HTTP 서버가 없고, 각 Git 실습은 README에서 확인합니다. 원격 GitHub PR/리뷰/병합은 학습자 계정으로 직접 실행해야 합니다.
