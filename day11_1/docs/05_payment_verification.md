# 실제 Supabase 모의 결제 검증 결과

- 실행 시각: 2026-10-29 16:02:33 KST
- 방식: 실행 중인 실제 HTTP 서버 → 실제 Supabase HTTP API → 실제 PostgreSQL 함수
- 실제 PG 호출·금액 청구 없음. 고유한 테스트 회원·상품만 사용.
- 기존 회원·상품·주문 데이터 및 기존 상품 재고는 변경하지 않음.

| 검증 항목 | 결과 | 확인 내용 |
| --- | --- | --- |
| 비로그인 결제 차단 | 통과 | HTTP 401 |
| 실DB 회원가입·인증 | 통과 | 테스트 회원 2명 생성, HttpOnly 쿠키 인증 |
| 장바구니 저장·재조회 | 통과 | API와 실제 DB 모두 동일 상품 2개 저장 확인 |
| 장바구니 주문 확정 | 통과 | CART → ORDERED, 1,000원 × 2개, 결제 전 재고 10개 유지 |
| 결제·동시 중복 요청 | 통과 | 동시 요청 2회에도 결제 1건, 결제액 2,000원, 재고 10 → 8 |
| 결제 완료 후 재시도 | 통과 | 새 요청 번호로 재시도해도 추가 결제·추가 차감 없음 |
| 구매내역·결제 상세 | 통과 | 결제 완료 주문 및 실제 payments 기록 조회 성공 |
| 바로 구매·가격 스냅샷 | 통과 | 기존 장바구니 보존, 가격 변경 후에도 확정 금액 1,000원으로 결제, 재고 8 → 7 |
| 다른 회원 주문·결제 차단 | 통과 | 조회 및 결제 요청 모두 HTTP 404, 재고 불변 |
